# 全球新闻标题聚合器

一个自动化的全球新闻标题聚合工具，可以定期抓取世界主要新闻网站的最新标题，并整合到一个清晰的本地网页界面中展示。

## 功能特性

### 📰 新闻来源
- **BBC News** - 英国广播公司新闻
- **CNN** - 美国有线电视新闻网
- **Reuters** - 路透社
- **Al Jazeera** - 半岛电视台
- **New York Times** - 纽约时报（仅公开内容）
- **The Guardian** - 卫报
- **Associated Press** - 美联社
- **日经新闻** - 日本经济新闻
- **NHK** - 日本放送协会
- **人民网** - 中国人民网
- **澎湃新闻** - 中国澎湃新闻

### 🎯 核心功能
1. **自动定期抓取** - 每30分钟自动抓取一次新闻
2. **智能HTML解析** - 自动分析网页结构，提取新闻标题和链接
3. **新闻分类** - 自动按主题分类（国际、政治、商业、科技等）
4. **标题去重** - 自动去除重复的新闻标题
5. **本地界面** - 生成清晰的本地HTML网页界面
6. **实时搜索** - 支持按标题关键字搜索
7. **来源过滤** - 可按新闻来源筛选
8. **自动刷新** - 页面自动定期刷新显示最新内容

### 🛡️ 稳定性保障
- **错误重试机制** - 请求失败时自动重试
- **容错处理** - 某个网站无法访问时不影响整体运行
- **HTML结构变化适应** - 自动容错处理网页结构变化
- **详细日志记录** - 完整记录所有操作和错误信息

## 技术实现

### 编程语言
- **Python 3.6+** - 核心爬虫和数据处理

## 使用说明

### 访问界面

生成的HTML界面文件位于项目根目录：`index.html`

您可以通过以下方式访问：

1. **直接双击打开** - 找到`index.html`文件并双击
2. **浏览器中打开** - 打开浏览器，选择"文件" → "打开文件"，然后选择`index.html`
3. **命令行打开** - 在命令行中运行`start index.html`

### 界面功能

#### 1. 新闻来源列表（左侧）
- 显示所有支持的新闻来源
- 点击"全部来源"显示所有新闻
- 点击特定来源只显示该来源的新闻
- 当前选中的来源会高亮显示

#### 2. 搜索功能（顶部）
- 在搜索框中输入关键字
- 系统会实时过滤包含关键字的新闻标题
- 搜索结果会动态更新

#### 3. 新闻统计（顶部）
- 显示当前可见的新闻总数
- 显示最后更新时间

#### 4. 新闻卡片（主区域）
- 每条新闻显示为一个卡片
- 包含新闻来源、分类、发布时间
- 新闻标题可点击跳转到原始网页
- 鼠标悬停时卡片会有动画效果

### 自动更新功能

#### 1. 后台自动抓取
- 新闻每30分钟自动抓取一次
- 抓取的新闻会保存到`data/news.json`文件
- 同时会更新`index.html`界面

#### 2. 页面自动刷新
- 网页会每30分钟自动刷新一次
- 刷新时会显示"新闻已更新"的提示
- 如果用户有交互操作（鼠标移动、键盘输入等），会延迟刷新时间

#### 3. 手动触发更新
- 您可以随时手动运行抓取脚本：
  ```bash
  python news_crawler.py
  ```
- 或者使用调度器运行一次：
  ```bash
  python scheduler.py --run
  ```

### 调度器使用

调度器脚本`schedule.py`提供了更高级的控制功能：

#### 1. 启动调度器
```bash
python scheduler.py --start
```
- 启动后会在后台运行
- 每30分钟自动抓取新闻
- 可以使用Ctrl+C停止

#### 2. 查看调度信息
```bash
python scheduler.py --info
```
- 显示当前时间
- 显示下次运行时间
- 显示所有新闻来源信息

#### 3. 立即运行一次
```bash
python scheduler.py --run
```
- 不启动调度器，立即运行一次新闻抓取

## 配置说明

### 新闻来源配置

在`news_crawler.py`文件中，`NEWS_SOURCES`字典定义了所有新闻来源的配置：

```python
NEWS_SOURCES = {
    'bbc': {
        'name': 'BBC News',
        'url': 'https://www.bbc.com/news',
        'selector': 'h3[data-testid="card-headline"]',
        'link_selector': 'a[data-testid="card-link"]'
    },
    # 其他新闻来源...
}
```

您可以根据需要添加或修改新闻来源。

### 分类关键词配置

在`news_crawler.py`文件中，`CATEGORY_KEYWORDS`字典定义了新闻分类的关键词：

```python
CATEGORY_KEYWORDS = {
    '国际': ['国际', 'world', 'global', 'international'],
    '政治': ['政治', 'politics', 'government', 'election'],
    # 其他分类...
}
```

您可以根据需要添加或修改分类关键词。

### 调度间隔配置

在`scheduler.py`文件中，您可以修改调度间隔：

```python
# 每30分钟运行一次
schedule.every(30).minutes.do(run_news_crawler)
```

支持的间隔单位：
- `minutes` - 分钟
- `hours` - 小时
- `days` - 天

## 常见问题

### 1. 运行时出现"ModuleNotFoundError"错误

这表示缺少Python依赖库。请运行启动向导或手动安装依赖：

```bash
python -m pip install -r requirements.txt
```

### 2. 抓取的新闻数量很少或为零

可能的原因：
- 网络连接问题
- 新闻网站结构发生变化
- 网站阻止了爬虫访问

解决方法：
- 检查网络连接
- 查看日志文件获取详细错误信息
- 如果是网站结构变化，可能需要更新新闻来源的选择器配置

### 3. HTML界面无法显示或显示异常

可能的原因：
- 新闻抓取失败，没有生成数据
- HTML生成过程中出现错误
- 浏览器兼容性问题

解决方法：
- 检查日志文件获取详细错误信息
- 尝试重新运行新闻抓取
- 使用现代浏览器（Chrome、Firefox、Safari等）

### 4. 自动更新功能无法正常工作

可能的原因：
- 调度器未启动
- 网络连接不稳定
- 系统防火墙阻止了网络访问

解决方法：
- 确保调度器已启动
- 检查网络连接
- 查看日志文件获取详细错误信息

## 性能优化建议

### 1. 减少不必要的抓取频率
- 默认每30分钟抓取一次，您可以根据需要调整
- 过于频繁的抓取可能会被网站阻止

### 2. 优化新闻来源配置
- 如果某个网站经常无法访问或结构经常变化，可以考虑暂时移除
- 可以根据自己的兴趣添加特定的新闻来源

### 3. 定期清理日志文件
- 日志文件会随着时间不断增大
- 建议定期清理或归档旧的日志文件

## 注意事项

### 1. 遵守网站的使用条款
- 在使用本工具之前，请确保您遵守各个新闻网站的使用条款
- 某些网站可能禁止爬虫访问，使用时请务必注意

### 2. 合理控制抓取频率
- 过于频繁的抓取可能会给新闻网站的服务器造成负担
- 建议不要将抓取间隔设置得太短（至少15分钟以上）

### 3. 数据使用限制
- 本工具仅用于个人学习和研究目的
- 抓取的新闻数据仅供个人使用，不得用于商业用途

### 4. 网络安全
- 使用本工具时请注意网络安全
- 建议使用可靠的网络连接，避免在不安全的网络环境中使用
